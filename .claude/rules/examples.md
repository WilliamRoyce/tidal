# Example Conventions

## Structure
Each example has: `examples/<name>/theory.toml` + `examples/<name>/<name>.wls` + `examples/data/<name>.json`
The .wls is auto-generated by `tidal derive theory.toml`. JSON is the solver input.

## TOML Conventions
- `[theory]` section: name, dimensions, metric
- `[[fields]]` sections: field definitions with rank, components
- `[[background_fields]]` section: externally imposed fields (not EOM-checked)
- `[[gauge]]` section: gauge fixing presets (Lorenz, de Donder, Coulomb, temporal, axial)
- `[[linearization.matter_perturbations]]`: for multi-field perturbation (xPert)

## Constant Naming
- **No underscores** — `mPhi2` not `m_phi_2`, `Bpeak` not `B_peak`
- Use `DefConstantSymbol` in Wolfram, not bare Symbol

## Simulation Pattern
```bash
uv run tidal simulate examples/data/<name>.json \
  --grid-shape N --bounds 0:L --periodic \
  --ic gaussian --ic-amplitude 0.1 --ic-width 1.5 --ic-center X --ic-component FIELD \
  --t-end T --output /tmp/tidal_tests/<name> --param key=val
```

## Sweep Scripts
- Located at `examples/<name>/sweep_*.sh`
- Include physics context in comments (formulas, references)
- Always use `--resume` for interruptible sweeps
- Default `--parallel 4` unless Wolfram is involved
