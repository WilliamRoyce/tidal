# Literature & References

When citing or referencing physics papers:
1. Check `Literature/` first — 8 arXiv TeX sources are stored locally
2. Read the TeX source directly (faster than WebFetch)
3. Key papers available locally:
   - Gertsenshtein: 2301.02072 (Domcke, simple derivation), 2310.04150 (Domcke, magnetic environments), 2406.17853 (Dandoy, GW constraints), 2507.16609 (Domcke, GW scattering)
   - Torsion: 2406.12826 (Barker, PGT conformal), 2410.01355 (Obukhov, spin-torsion), hep-th/0103093 (Shapiro, spacetime torsion)
   - Related: 2405.08865 (Berlin, axion-photon numerical methods)
4. For new papers: download TeX from arXiv, extract to `Literature/<id>/`
5. Update `docs/references.md` when adding new references
