## Issue 1: Energy measurement missing sqrt|g| for curved coordinates

**Title:** Energy measurement fails for curved coordinate systems (missing metric determinant)

**Labels:** enhancement, energy-measurement

**Body:**

### Description

The energy conservation measurement (`tidal measure --what conservation`) fails for all curved coordinate examples, even when the metric is time-independent and energy should be conserved.

### Affected examples

| Example | max |dE/E| | Expected |
|---------|-----------|----------|
| polar_kg | 4.35e-01 | ~0 |
| sphere_kg | 6.62e-01 | ~0 |
| spherical_kg | (untested, same issue) | ~0 |
| cylindrical_kg | (untested, same issue) | ~0 |

Note: `de_sitter_kg` also shows 30.9% energy change but this is physically expected -- the time-dependent metric (Hubble expansion) means energy is not a conserved quantity.

### Root cause

The Hamiltonian energy density integration in `_energy.py` does not weight by the metric determinant `sqrt|g|`. For curved coordinates:

- Polar: `sqrt|g| = r`
- Spherical (surface): `sqrt|g| = R^2 sin(theta)`
- Spherical (3D): `sqrt|g| = r^2 sin(theta)`
- Cylindrical: `sqrt|g| = r`

The total energy should be `E = integral(H * sqrt|g| * dx)`, not `E = integral(H * dx)`.

### Note

All 13 Cartesian-coordinate examples pass energy conservation (all < 1e-3). The solver layer is correct -- this is purely an energy measurement integration issue.

### Suggested fix

1. Store the metric matrix (or sqrt|g| expression) in the JSON spec
2. In `_compute_hamiltonian_from_canonical`, weight the energy density by sqrt|g| before spatial integration

## Issue 2: Rename data.momenta attribute to data.velocities

**Title:** Rename SimulationData.momenta to SimulationData.velocities

**Labels:** enhancement

**Body:**

### Description

After the E-L velocity form refactoring, `SimulationData.momenta` stores velocities `v = dq/dt`, not canonical momenta `pi = K*v + S`. The naming is confusing.

### Affected files

- `tidal/measurement/_io.py` -- `SimulationData` class
- `tidal/measurement/_energy.py` -- references to `data.momenta`
- `tidal/measurement/_writer.py` -- snapshot writer
- Tests referencing `data.momenta`

### Priority

Low -- cosmetic change, no functional impact. File naming is already correct (`v_*.npy`).

## RESOLVED: Background field Hamiltonian substitution (was Issue 2)

**Status:** Fixed in commit 21548b8

The `_wls_vector_background_substitution` function only generated indexed-form rules (`vbdB[{i, -chart}] -> value`) but after `DecomposeScalarExpression`, the expression contained component-function form (`vbdBi[t, x, y]`). Fix adds function-form rules (`vbdBi[__] -> value`).

After re-derivation, vector_background energy conservation: PASS (max |dE/E| = 2.78e-06).

## RESOLVED: proca_background energy conservation (was Issue 3)

**Status:** Resolution issue, not a bug

At 16x16 grid: max |dE/E| = 5.43e-03 (FAIL)
At 24x24 grid with rtol=1e-5: max |dE/E| = 4.24e-04 (PASS)
