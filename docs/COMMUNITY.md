# Community Guidelines

## Getting Help

TIDAL has multiple support channels depending on your needs:

### GitHub Discussions (Recommended)
https://github.com/WilliamRoyce/torsion-gertsenshtein/discussions

Use Discussions for:
- **Questions** about usage, implementation, or physics
- **Show & Tell** — Share your research or simulations using TIDAL
- **Ideas** — Discuss potential features or improvements before opening issues
- **General Discussion** — Talk about field theory, tensor algebra, numerical methods

### Issue Tracker
https://github.com/WilliamRoyce/torsion-gertsenshtein/issues

Use Issues for:
- **Bug Reports** — Something broken? Use the bug template
- **Feature Requests** — Specific, actionable enhancements
- **Documentation Improvements** — Unclear or missing docs

### Documentation
https://williamroyce.github.io/torsion-gertsenshtein/

Includes:
- API reference
- Pipeline architecture
- Example gallery with 18 working examples
- Troubleshooting guide

## Communication Expectations

- **Response time**: Best-effort (this is academic research software)
- **Language**: English preferred
- **Tone**: Professional, collegial, curious

See [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) — we follow the standard open-source code of conduct.

## Acknowledgments

Contributors are credited in:
- Git commit history (preserved via proper attribution)
- Pull request descriptions
- Future: `CONTRIBUTORS.md` (when we have external contributors)

## Academic Use

If you use TIDAL in research:
1. Cite via `CITATION.cff` (Zenodo DOI integration planned)
2. Consider opening a Discussion in "Show & Tell" to share your work
3. Link back to this repository in publications

## Funding

TIDAL is currently unfunded academic research. If you'd like to support development, contact the author or watch for future funding options.
