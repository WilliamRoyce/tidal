\section{Examples}
\label{sec:examples}

TIDAL includes 20 pipeline examples spanning 1+1D through 3+1D spacetimes with scalar, vector, and tensor fields.

\subsection{Pipeline Examples}

All pipeline examples follow the same pattern: \texttt{tidal derive theory.toml} derives equations from a Lagrangian (via \texttt{wolframscript}), exports to JSON, and a Python script or CLI command runs the simulation.

\subsection{Running Examples}

\subsubsection{With the CLI}

\begin{lstlisting}[style=bash]
# List available JSON specifications
tidal list

# Run a simulation
tidal simulate examples/data/klein_gordon_1d.json --t-end 20 --ic gaussian

# Derive from TOML (requires wolframscript)
tidal derive examples/scalar_field/theory.toml --run
\end{lstlisting}

\subsubsection{With \texttt{run.sh} scripts}

Most examples include a \texttt{run.sh} script that runs the full pipeline:

\begin{lstlisting}[style=bash]
cd examples/scalar_field
bash run.sh
\end{lstlisting}

Each example directory has a \texttt{run.sh} that runs the full pipeline:

\begin{lstlisting}[style=bash]
cd examples/scalar_field && bash run.sh
cd examples/scalar_vector_coupling && bash run.sh
\end{lstlisting}

\subsubsection{Running Sweep Examples}

\begin{lstlisting}[style=bash]
# Run from the example directory
cd examples/coupled_scattering && bash sweep_adaptive.sh

# Or use a TOML config directly
tidal sweep --config examples/coupled_scattering/sweep_advanced.toml

# Visualize results
tidal plot sweeps/output/ --type sweep --metric P_max
\end{lstlisting}

\subsection{JSON Specification Files}

All generated JSON files live in \texttt{examples/data/}:

\begin{lstlisting}[style=bash]
ls examples/data/*.json
\end{lstlisting}

Each JSON file is a self-contained equation system specification that can be loaded with:

\begin{lstlisting}[style=python]
from tidal.symbolic.json_loader import load_equation_system

spec = load_equation_system("examples/data/klein_gordon_1d.json")
\end{lstlisting}

See \cref{sec:pipeline} for details on the JSON schema.
