## Context

TIDAL is becoming a Cobaya extension: arbitrary Lagrangian → spectator-sector
perturbations on a CAMB-supplied ΛCDM background → CMB observables → real likelihoods.
The direct predecessor is the group's TorC paper (local:
`literature/2507.09228/paper_Qtorsion.tex`): PSALTer spectrum → modified CAMB → modified
Cobaya → PolyChord vs Planck 2018 + SH0ES. It modified only the *background* (tabulated
`ρ_Λ^eff(a)`, `P_Λ^eff(a)`) and kept ΛCDM perturbations. Our first science target (O1) is
to **recreate that analysis through our own pipeline** as the end-to-end plumbing gate,
using TorC's published `ρ_Λ^eff`, `P_Λ^eff` as input tables via a *general*
tabulated-background feature. TorC is a validation case, not a foundation — no TorC
dependence in the package.
