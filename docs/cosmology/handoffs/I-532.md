## Why this exists

Everything downstream stands on one seam: the single place CAMB is called, and the protocol
that says what our engine may ask of a background. Neither exists. `repo_reshape.md:940`
names `background/protocol.py` as **this milestone's first deliverable, defined by
investigating CAMB's API**. Around it:

- **The O0 gate is circular unless held to identity.** The pass-through returns CAMB's own
  arrays, so "sub-percent agreement with CAMB" tests nothing; the gate is
  **machine-precision identity**, which can only catch a convention slip — a unit,
  `ℓ(ℓ+1)/2π`, lensed-vs-unlensed, a grid. That is why the conventions must be an artifact
  (`repo_reshape.md:940`, the M1a milestone row).
- **The flag schema does not exist and the tree contradicts itself.** Five documents reference
  a shared flagged-rejection mechanism; none defines a flag's fields or severity
  (`scientific_review.md:190-194`). `tidalcosmo/validity/README.md:28-30` says "a flag is a
  diagnostic, **never a gate** — GH #454"; `spectrum/README.md:17-25` and
  `stage1_engineering_plan.md:786-791` describe the spectrum verdict as a rejection inside the
  sampling loop, before any forward solve is spent.
- **Where a veto is raised in Cobaya is written nowhere**, and it is not ours to invent. The
  group's own codes — TorC and the polology/PSALTer line — already apply numerical health and
  validity checks somewhere, with some severity, and report rejections somehow. People with
  more statistical expertise settled those questions; **v1 follows their practice**.
- **The A8 reachability note.** The self-validation ladder's tensor leg (WS3, M4) will
  re-evolve the gravitational-wave mode with CAMB's own equation and compare to CAMB's own
  `h(k,η)`; CAMB sources that equation with the standard sectors' anisotropic stress. The
  audited Python API (`repo_reshape.md:248`) exposes photon quantities but no neutrino one,
  and may not expose tensor `h(k,η)` at all. **Not a deliverable here** — but you are inside
  that API anyway, so answer it in passing (a few lines in the protocol notes) rather than
  leave it unknown for WS3.
