  \vspace{0.2em}
  \textbf{Core claim.} \emph{Every equation the numerics solves is traceable back to a single Lagrangian I typed in.} No hand-derived PDEs. No manual index gymnastics.

  \vspace{0.2em}
  \textbf{Why it matters here.} This project varies the Lagrangian \emph{dozens} of times --- different torsion operators, couplings, gauges, plasma backgrounds. Hand-deriving each variation would be intractable and unreliable.
