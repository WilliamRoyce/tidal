\begin{frame}{Motivation}
  \begin{itemize}
    \setlength{\itemsep}{1.5ex}
    \item The standard Gertsenshtein effect ($g \leftrightarrow \gamma$ conversion in a $B$-field) is textbook Einstein--Maxwell theory --- and \emph{astrophysically negligible}.
      \begin{itemize}
        \item Magnetar: $P\sim 10^{-10}$, Laboratory: $P\sim 10^{-40}$.
      \end{itemize}
    \item For any usable signal, new physics is required. The question is: \emph{which?}
    \item Unapologetically phenomenological: systematically scan the space of extensions of GR, and ask which sectors amplify.
  \end{itemize}
\end{frame}
