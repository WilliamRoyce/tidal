\begin{frame}{Motivation}
  \small
  \begin{itemize}
    \item No detector at $\gtrsim$ MHz.  Possible sources: early-universe processes, PBH mergers, evaporating PBHs.

    \item Existing reanalyses use the Gertsenshtein effect: photon backgrounds [1,\,2]; DM cavities [3,\,4].

    \item Bare GR mixing length $\sim 10^{6}$\,km at magnetar $B$ --- too long for any astrophysical source.

    \item \textbf{Gap}: can BSM gravity amplify the conversion?  Not yet computed beyond Einstein--Maxwell.
  \end{itemize}
