\begin{frame}{The Gertsenshtein effect}
  \textbf{Setup.} Linearised GR $+$ Maxwell $+$ uniform background $B_0$.

  \vspace{0.3em}
  \textbf{Why they mix.} The EM action $\propto F_{\mu\nu}F^{\mu\nu}$ contains \emph{two} metric factors $g=\eta+h$. Perturbing the metric around a $B_0$ background generates a cross-term between $h$ and $\delta A$.

  \vspace{0.3em}
  \textbf{Result:}
  \[
    P_{g\to\gamma}(D) = \sin^{2}\! \left(\tfrac{1}{2}\kappa B_0 D\right)
  \]

  \begin{itemize}
    \item Same structure as two-state QM / axion--photon conversion.
    \item Background $B_0$ plays the role of the off-diagonal coupling.
  \end{itemize}
\end{frame}
