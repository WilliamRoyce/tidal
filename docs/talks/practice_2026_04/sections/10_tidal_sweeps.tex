\begin{frame}{Causality screening built into the inference}
  \note{\textasciitilde 12 min mark. The abstract's "causality / characteristic speeds" slide. Honest framing: what's implemented is all-mode eigenvalue stability pre-screening, not formal characteristic-speed analysis.}
  \textbf{The challenge.} A phenomenological scan will visit Lagrangians with tachyonic / gradient-unstable modes. We need to reject those \emph{before} simulation, not after.

  \vspace{0.2em}
  \textbf{The mechanism.} For every parameter point in the scan:
  \begin{enumerate}\small
    \item Build the modal evolution matrix $M(k)$ at every spatial wavenumber $k$.
    \item Compute $\max_{k}\,\mathrm{Re}\,\lambda(k)$ across the spectrum.
    \item If $> 0$: linearisation has a growing mode --- reject the parameter point.
  \end{enumerate}

  \vspace{0.2em}
  \textbf{Wired into the Bayesian inference prior, not as a post-hoc filter.}
  \begin{itemize}\small
    \item Tachyonic samples get $\log\mathcal{L} = -\infty$. PolyChord literally never samples there.
    \item Cost: $\sim\!1$\,ms per sample; $\sim\!5$\,s for a 5000-point prior draw.
    \item The same machinery catches tachyons and ghosts that would otherwise masquerade as amplification --- the sampler spends its entire budget on physically viable regions.
  \end{itemize}
  \vspace{0.2em}
  \emph{In a phenomenological scan, the cheapest sanity check has to be embedded in the prior. Otherwise the inference spends most of its time where the linearisation is invalid.}
\end{frame}
