\begin{frame}{The operator landscape}
  PGT's quadratic Lagrangian contains many independent couplings, broadly:
  \[
    \mathcal{L} \supset
      \underbrace{\mathcal{T}^2}_{\text{mass}}
      + \underbrace{(\nabla \mathcal{T})^2}_{\text{kinetics}}
      + \underbrace{\Rt^2}_{\text{curv. kinetics}}
      + \underbrace{\Rt\times F}_{\text{non-min.}}
      + \underbrace{\Rt\times\nabla \mathcal{T}}_{\text{deriv. mix}}
      + \cdots
      - \tfrac{1}{4}F^2
  \]
  Each sector adds several contractions; parity-odd partners double the count.

  \vspace{0.6em}
  \centering\emph{Manual derivation is fragile; surveying the landscape needs a computational pipeline.}
\end{frame}
