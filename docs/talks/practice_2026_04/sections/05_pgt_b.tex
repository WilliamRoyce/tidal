\begin{frame}{The operator landscape}
  \emph{Which subsectors of quadratic curvature \& torsion modifications amplify the conversion?}

  \vspace{0.6em}
  PGT's quadratic Lagrangian contains many independent couplings, broadly:
  \[
    \mathcal{L} \supset
      \underbrace{\mathcal{T}^2}_{\text{mass}}
      + \underbrace{(\nabla \mathcal{T})^2}_{\text{kinetics}}
      + \underbrace{\Rt^2}_{\text{curv. kinetics}}
      + \underbrace{\Rt\times F}_{\text{non-min.}}
      + \underbrace{\Rt\times\nabla \mathcal{T}}_{\text{deriv. mix}}
      + \cdots
      - \tfrac{1}{4}F^2
  \]
  Each sector contributes several independent contractions, and parity-odd partners ($\eps$-contractions) double each row.

  \vspace{0.6em}
  \centering\emph{Manual derivation of one Lagrangian's linearised PDEs is fragile and slow.  Surveying the landscape requires a systematic computational pipeline.}
\end{frame}
